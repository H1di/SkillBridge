# SkillBridge

## What This Website Uses

- `HTML` for page structure
- `CSS` for design and layout
- `JavaScript` for frontend animations, forms, scripts
- `Python` for the local backend server
- `SQLite` for storing local app data in `data/skillbridge.db`


## To launch in local environment 
Run:

bash
python3 server.py

Open:
http://localhost:8000

Backend features only work when the Python server is running.
If you open just index.html, a lot of features will be not available

Also, you can open instead a deployed website: https://skillbridge-hi82.onrender.com/
